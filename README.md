# 黑道風雲：地下帝國（Underworld Empire）

台灣現代背景的單人策略故事遊戲。故事角色、組織與事件皆為虛構。

## 故事模式原型 v0.1
主角林奕辰，29 歲，出身台北萬華。前輩病倒後，他接下規模很小的地方組織，必須在夥伴信任、地方觀感、有限資源與外部壓力之間做出選擇。

目前包含：
- 故事模式序章：兩個可遊玩章節
- 三選一劇情決策
- 聲望、信任、資金、外部關注四項狀態
- 選擇結果與事件紀錄
- 桌面與手機響應式介面

## 本機執行
```bash
npm install
npm run dev
```

## 建置
```bash
npm run build
```

## 設計原則
本作是架空娛樂作品。犯罪題材僅以抽象敘事與數值呈現，不提供現實犯罪操作指引；不影射真實人物或組織。

## 開發狀態
v0.1 為可操作的故事模式序章原型。完整 22 縣市地圖、存檔、AI 勢力、人物關係網與多結局系統仍待後續版本開發。
