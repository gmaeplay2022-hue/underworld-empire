# 江湖（JIANGHU）

現代文明社會背景的虛構台灣地下勢力經營策略遊戲。人物、組織、地點及事件均為原創虛構設定。

## 正式開發規格
《江湖》正式遊戲開發規格 V1.0：[`docs/GAME_DESIGN_SPEC_V1.md`](docs/GAME_DESIGN_SPEC_V1.md)

核心方向：
- 虛擬台灣 22 縣市，第一版規劃 96 個虛構地盤
- 動態生成世界、8 個主要 AI 勢力及自然演變的地方組織
- 地盤採主要控制者＋多方影響力的 Hybrid 模型
- 平衡的初始勢力密度，保留中立區與無主空地
- 玩家自由選擇開局地點，預設標準難度
- 每日一回合、長期動態世界、10 個手動存檔槽及 1 個自動存檔槽

## 目前原型

### V0.1 故事模式
- 兩個可遊玩章節
- 三選一劇情決策
- 聲望、信任、資金、外部關注四項狀態
- 選擇結果與事件紀錄
- 桌面與手機響應式介面

### V0.2 世界建立器（核心完成，持續完善）
- 固定 22 縣市與 96 個初始地盤資料
- 以 World Seed 重現世界初始勢力分布
- 8 個主要 AI 勢力模板，開局由其中 6–8 個取得地盤
- 8–10 個地方組織、18 個中立地盤及 26 個無主地盤
- Hybrid 地盤控制與獨立影響力資料
- 縣市示意地圖、地盤清單及地盤資料面板
- 玩家可選擇中立或無主地盤建立組織
- IndexedDB 自動存檔 1 槽、手動存檔 10 槽
- 初始世界生成與資料模型測試
- 玩家組織建立後可進行每日回合結算
- 每日收入、維持支出、資金、聲望、信任與公共壓力
- 地方公益、內部治理、長期建設三種抽象政策
- AI 勢力影響力每日緩慢變化（不自動奪取地盤）

注意：目前的地圖是可互動的縣市示意排布，並非精確行政地圖；每日回合與基礎經營已開始實作，完整 AI 決策、勢力自然成長、外交、人物世代、衝突與完整長期遊戲循環仍在開發。

## 設計原則
本作是架空娛樂作品。犯罪題材僅以抽象敘事與策略數值呈現，不提供現實犯罪操作指引；不影射真實人物或組織。

## 開發狀態
V0.1 故事模式原型已建立；V0.2 世界建立器與 V0.3 每日經營核心正在整合。CI 建置結果以 GitHub Actions 最新執行狀態為準。功能是否完成以實際程式與測試結果為準。
