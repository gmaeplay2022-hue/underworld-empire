# 江湖（JIANGHU）

現代文明社會背景的虛構台灣地下勢力經營策略遊戲。人物、組織、地點及事件均為原創虛構設定。

## 正式開發規格
《江湖》正式遊戲開發規格 V1.0：[`docs/GAME_DESIGN_SPEC_V1.md`](docs/GAME_DESIGN_SPEC_V1.md)

核心方向：
- 虛擬台灣 22 縣市，第一版規劃 96 個虛構地盤
- 動態生成世界、8 個主要 AI 勢力及自然演變的地方組織
- 地盤採主要控制者＋多方影響力的 Hybrid 模型
- 平衡的初始勢力密度，保留中立區與無主空地
- 玩家自由選擇開局地點，預設標準難度
- 每日一回合、長期動態世界、10 個手動存檔槽及 1 個自動存檔槽

## 目前原型
目前包含故事模式序章原型：
- 兩個可遊玩章節
- 三選一劇情決策
- 聲望、信任、資金、外部關注四項狀態
- 選擇結果與事件紀錄
- 桌面與手機響應式介面

## 本機執行
```bash
npm install
npm run dev
```

## 建置
```bash
npm run build
```

## 設計原則
本作是架空娛樂作品。犯罪題材僅以抽象敘事與策略數值呈現，不提供現實犯罪操作指引；不影射真實人物或組織。

## 開發狀態
V0.1 故事模式原型已建立。正式地圖、世界生成、存檔、AI、人物與經濟系統依 V1.0 規格分階段開發。尚未完成的功能不應標示為已實作。
