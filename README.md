# 江湖（JIANGHU）

現代文明社會背景的虛構台灣組織經營策略遊戲。人物、組織、地點及事件均為原創虛構設定。\n\n**目前版本：0.3.0 可遊玩核心版**（V1.0 正式發行前持續完善）。

## 正式開發規格
《江湖》正式遊戲開發規格 V1.0：[`docs/GAME_DESIGN_SPEC_V1.md`](docs/GAME_DESIGN_SPEC_V1.md)

核心方向：
- 虛擬台灣 22 縣市，第一版規劃 96 個虛構地盤
- 動態生成世界、8 個主要 AI 勢力及自然演變的地方組織
- 地盤採主要控制者＋多方影響力的 Hybrid 模型
- 平衡的初始勢力密度，保留中立區與無主空地
- 玩家自由選擇開局地點，預設標準難度
- 每日一回合、長期動態世界、10 個手動存檔槽及 1 個自動存檔槽

## 目前原型

### V0.1 故事模式
- 兩個可遊玩章節
- 三選一劇情決策
- 聲望、信任、資金、外部關注四項狀態
- 選擇結果與事件紀錄
- 桌面與手機響應式介面

### 可遊玩核心（V0.3 開發階段）
- 固定 22 縣市與 96 個初始地盤資料
- 以 World Seed 重現世界初始勢力分布
- 8 個主要 AI 勢力模板，開局由其中 6–8 個取得地盤
- 8–10 個地方組織、18 個中立地盤及 26 個無主地盤
- Hybrid 地盤控制與獨立影響力資料
- 縣市示意地圖、地盤清單及地盤資料面板
- 玩家可選擇中立或無主地盤建立組織
- IndexedDB 自動存檔 1 槽、手動存檔 10 槽
- 初始世界生成與資料模型測試
- 玩家組織建立後可進行每日回合結算
- 每日收入、維持支出、資金、聲望、信任與公共壓力
- 地方公益、內部治理、長期建設三種抽象政策
- AI 勢力影響力、資源、凝聚力與外交關係會隨回合演變
- 30 天週期可自然生成新地方組織
- 玩家可協商外交、招募幹部、投資地盤及進行抽象地盤協調
- 人物年齡、健康、忠誠、能力與家族世代資料
- 領導者退休後會觸發接班與家族世代交替
- 舊版存檔遷移、世界 JSON 匯入與匯出

地圖是可互動的縣市示意排布，並非精確行政地圖。這是可遊玩的開發版核心；完整人物關係網、更多事件決策、長期平衡及正式發行前的跨瀏覽器驗證仍需持續完善。

```bash
npm install
npm run dev
```

## 測試
```bash
npm test
```

## 建置
```bash
npm run build
```

GitHub Actions 會在 main 分支更新時執行單元測試與 TypeScript／Vite 正式建置，通過後自動部署至 GitHub Pages。Playwright 端對端測試目前仍列為後續驗收項目。，並產生可下載的 `jianghu-web-build` 網頁建置檔。下載方式請見遊玩指南。

## 設計原則
本作是架空娛樂作品。犯罪題材僅以抽象敘事與策略數值呈現，不提供現實犯罪操作指引；不影射真實人物或組織。

## 開發狀態
目前已具備世界建立、組織經營、每日回合、AI 勢力、外交、人物世代、地盤競爭與本機存檔的可遊玩核心。版本仍在 V1.0 正式整合前的開發階段；功能完成度以程式與最新 CI 結果為準。
