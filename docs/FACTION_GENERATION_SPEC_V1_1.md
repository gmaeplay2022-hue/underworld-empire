# 《江湖》人物與勢力生成規格 V1.1

- 文件狀態：正式整合版本
- 適用範圍：新世界初始生成、AI 勢力、人物配置、地區影響、外交關係與長期演化
- 基礎世界：架空台灣 22 縣市、96 個虛構地盤
- 生成原則：相同世界種子與相同生成器版本，重現相同的初始遊戲資料

## 1. 已確認決策

| 項目 | 正式規格 |
|---|---|
| 整體生成方案 | 整套採用 |
| 初始 AI 核心勢力 | 8 個 |
| 初始勢力密度 | 均衡型 |
| 起始地區 | 依世界種子動態分配全台灣 |
| 人物生成規模 | 完整生成 |
| 世界初始局勢 | 世界種子自動決定 |
| 勢力名稱 | 世界種子自動生成 |
| 重要人物更替 | 允許自然更替 |
| 新勢力 | 符合條件時自然產生 |
| 制度性力量 | 政治、行政、執法與司法獨立運作 |

## 2. 八大核心勢力配置

八個核心勢力原型固定，名稱、人物、據點、資源、關係與初始背景依世界種子生成。

| 原型 | 數量 | 規模傾向 | 主要發展方向 |
|---|---:|---|---|
| 地方組織 | 2 | 中型 | 地方人際網絡、社區信任、組織凝聚 |
| 商業勢力 | 1 | 大型 | 資金、合法商業往來、跨業合作 |
| 地方派系 | 1 | 中型 | 地方聲望、公共關係、地方議題 |
| 產業勢力 | 1 | 大型 | 產業鏈、物流、建設、區域資源 |
| 地下勢力 | 2 | 小型及中型 | 虛構非正式網絡、組織整合與生存 |
| 外來勢力 | 1 | 中型 | 跨區域聯繫、在地合作與拓展 |

勢力 ID 與名稱分離。更名不改變 ID、人物歸屬、外交關係或歷史紀錄。勢力名稱均為虛構，不對應真實犯罪組織。

## 3. 全台灣動態地區配置

- 地圖維持 22 縣市及 96 個虛構地盤。
- 每個核心勢力生成一個主要據點縣市及若干影響縣市。
- 主要據點依世界種子抽選；初始控制區域會優先在其主要據點配置。
- 允許多個勢力集中於同一縣市，也允許部分縣市沒有核心勢力據點。
- 勢力影響區域可以重疊。
- 主要控制權與多方影響力分開記錄。
- 初始均衡密度保留既有勢力、中立地方網絡及無主地盤，不代表所有勢力實力相等。

## 4. 完整人物生成

每個核心勢力及初始地方網絡建立下列人物：

| 人物層級 | 每個勢力初始配置 |
|---|---:|
| 領導人 | 1 |
| 核心幹部 | 2–3 |
| 重要成員 | 3–5 |

另由世界生成及後續事件建立地方關鍵人物與制度性人物。一般成員可採群體統計，不要求每人建立完整人物檔案。

重要人物資料包括：

- 穩定人物 ID、姓名、年齡、出身與所屬勢力。
- 職位、家族識別、世代及人物狀態。
- 領導、管理、外交等能力。
- 忠誠、信任、好感、敬重與恐懼等關係維度。
- 性格、價值觀、野心、個人目標與專長。
- 個人背景、經歷及歷史事件。

能力、性格與忠誠必須分開記錄，不以單一分數代表人物。人物姓名與 ID 分離。

## 5. 世界初始局勢傾向

世界種子自動決定以下五種傾向之一，並作為生成權重，而非固定劇本：

1. 商業競逐型：商業與產業資源較突出。
2. 地方派系型：地方關係與區域影響力較重要。
3. 產業發展型：產業、物流與資源網絡較突出。
4. 權力競爭型：多個勢力實力接近、競爭較頻繁。
5. 外來勢力型：跨區域勢力影響較明顯。

世界傾向不限制後續演化。玩家行動與 AI 決策可使局勢轉向其他型態。

## 6. 初始外交關係

勢力關係依地理接近、共同利益、產業互補、初始歷史與人物關係生成。關係類型包括友好合作、商業合作、互不侵犯、中立觀望、競爭、對立、敵對、停火、聯盟及附屬／依賴。

每段重要關係應能追溯形成原因。合作、中立、競爭及敵對比例屬生成目標，不是固定配額。關係會隨事件與決策變動。

## 7. 人物與勢力自然演化

人物可升遷、退休、離任、轉投或退出權力核心。領導人退休時啟動接班流程；幹部人事調整依組織凝聚力、忠誠及年度條件觸發。接班與人事調整須留下事件及歷史紀錄。

勢力可擴張、衰退、改組、分裂、合併、失去據點或解體。地方網絡可依長期條件自然形成新勢力。新勢力必須有背景及形成原因。

建議更新節奏：
- 每日：基本人物、資源與局勢更新。
- 每週：AI 策略、外交及組織調整。
- 每月：長期趨勢、勢力興衰與新網絡條件評估。
- 事件觸發：接班、分裂、重大人事變化及特殊事件。

## 8. 制度性人物與力量

政治、行政、執法及司法體系獨立於八大核心勢力。其人物具有自身職責、制度限制、立場與事件，不視為一般可招募角色。

## 9. 歷史、新聞與存檔

人物履歷、勢力歷史、世界事件及新聞摘要需共用同一組穩定 ID。人物離任、退休或退出組織後，歷史資料不得刪除。

世界存檔包含世界種子、生成器版本、勢力、人物、地區控制與影響力、關係、事件及歷史。相同世界種子在相同生成器版本下應重現相同的初始遊戲資料；建立時間等存檔中繼資料不屬於遊戲生成結果。載入存檔不得重新抽取世界。

## 10. 驗收標準

- [ ] 新世界生成八個核心勢力，原型數量符合本規格。
- [ ] 名稱由種子生成，且不重複。
- [ ] 每個核心勢力有主要據點及影響縣市。
- [ ] 初始控制區域優先與主要據點相符。
- [ ] 22 縣市、96 個地盤完整存在。
- [ ] 完整生成領導人、核心幹部及重要成員。
- [ ] 重要人物具有個性、目標、能力與關係資料。
- [ ] 世界傾向由種子決定。
- [ ] 初始外交關係具有合理形成因素。
- [ ] AI 可自主發展，人物及勢力能自然更替。
- [ ] 重大變化寫入世界事件及歷史。
- [ ] 相同種子與生成器版本可重現初始遊戲資料。
- [ ] 舊存檔可讀取，舊人物及勢力資料不被重置。

## 11. 實作版本紀錄

- 生成器版本升至 1.1.0。
- 保留既有 WorldState schemaVersion 2，新增人物與勢力欄位採選填方式，以維持舊存檔相容。
- 舊存檔不會在載入時重新生成八大勢力或完整人物名單；V1.1 生成規則適用於新建世界。
- 遊戲仍為單人瀏覽器版本，使用本機 IndexedDB 存檔。
