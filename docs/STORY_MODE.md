# 故事模式設定：崛起

## 作品定位
《黑道風雲：地下帝國》是以現代台灣為舞台的架空策略故事。整體採寫實黑幫電影的陰鬱氛圍，但角色、組織、事件皆為虛構。

## 主角
- 姓名：林奕辰
- 年齡：29 歲
- 出身：台北市萬華區
- 身分：地方小型組織代理負責人
- 性格：冷靜、重情、謹慎
- 核心矛盾：如何在照顧夥伴、維持地方信任與面對外部壓力之間取得平衡。
- 初始目標：穩住組織、處理前輩留下的問題，找到自己的領導方式。

## 核心狀態
- 地方聲望：社區與外界對主角的觀感。
- 團隊信任：夥伴對主角的信任程度。
- 可用資金：抽象遊戲資源。
- 外部關注：公共與制度層面的壓力指標。

## 序章章節
1. 雨夜的約定：前輩病倒，主角面對組織存續的第一個選擇。
2. 留下來的人：主角必須決定如何分配有限的時間與資源。

## 敘事規則
選擇應產生可見的狀態變化，並在後續章節反映人物關係與事件走向。避免將現實犯罪流程具體化；以人際、治理、社區關係、法律風險與組織存續等抽象系統表現題材張力。

## 後續章節方向
- 第三章：不速之客——外部勢力提出合作邀約。
- 第四章：舊帳——前輩留下的承諾逐漸浮現。
- 第五章：分岔路——團隊對未來方向產生分歧。
- 序章結局：依聲望、信任與外部關注形成不同敘事收束。
