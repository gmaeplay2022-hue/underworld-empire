# 《江湖》主介面與操作架構規格 V1.0

- 狀態：正式整合
- 介面方向：混合式策略指揮中心
- 故事定位：世界事件與人物故事的延伸內容；保留原序章故事入口
- 資訊密度：豐富資訊型，次要資料以功能分頁承載
- 視覺方向：既有深色、銅金色地方紀實風格，搭配策略遊戲資訊面板

## 1. 設計目標

主頁由故事展示頁調整為世界經營指揮中心。玩家進入已建立世界後，優先看到日期、資源、世界局勢、待處理事件及核心操作。地圖、勢力、人物、財務、外交、事件與存檔分區呈現，避免長頁面堆疊所有資料。

## 2. 全域操作區

- 品牌列：JIANGHU／世界指揮中心。
- 世界標題：世界名稱、種子、遊戲天數、難度及初始局勢。
- 常駐指揮列：遊戲天數、資金、聲望、信任、公共關注。
- 玩家已建立組織時，提供「推進下一天」操作。
- 主要功能採橫向可捲動分頁，桌面與窄螢幕均可操作。

## 3. 八個主功能分頁

| 分頁 | 內容 |
|---|---|
| 世界總覽 | 控制地盤、中立地盤、無主地盤、勢力數、組織概況、待處理事件、近期動態 |
| 地圖地盤 | 22 縣市選擇、96 地盤列表、地盤資料、勢力影響力與地方操作 |
| 勢力組織 | 主要 AI 勢力、據點、實力、目標、組織資料 |
| 人物名冊 | 領導者、核心幹部、重要人物、人物屬性與世代資訊 |
| 財務經營 | 玩家資金、每日收入支出、每日經營、政策、招募與回合推進 |
| 外交關係 | 各勢力關係狀態、關係分數、協商入口 |
| 任務事件 | 世界事件、待決策事件、選項處理、組織歷史紀錄 |
| 存檔管理 | 自動存檔、手動存檔、歷史版本、JSON 上下載與還原 |

## 4. 故事模式定位

原有序章仍可從主介面進入，定位為故事篇章入口。世界事件與人物名冊則提供日常世界敘事與人物資訊入口。序章原有獨立狀態仍需後續整合至 WorldState，確保劇情選擇與章節進度能隨世界存檔保存；本版不宣稱已完成該資料層整合。

## 5. 響應式與視覺

- 保留深色底、銅金色重點、低彩度資訊卡與既有字體方向。
- 重要資源固定出現在指揮列。
- 桌面使用多欄資訊卡；窄螢幕改為單欄並允許功能列水平捲動。
- 避免將所有管理模組一次展開，依功能分頁呈現。
- 事件、人物、勢力卡片保留既有資料，不以純展示圖取代可操作內容。

## 6. 本版整合範圍

已調整 WorldGame 主畫面分頁結構、指揮列、總覽卡片及響應式樣式。原有世界生成、地圖操作、勢力資料、人物資料、外交、事件與存檔功能沿用既有邏輯，依分頁重新組織。

## 8. 整合故障修復紀錄

先前主介面改版的 JSX 引用了未宣告的 `overviewTop`，會造成 TypeScript 編譯失敗，因而無法產生可部署的新版網站。已補上世界總覽卡片定義。另新增 GitHub Actions 工作流程：推送 main 後安裝依賴、執行單元測試、執行 TypeScript／Vite 建置，通過後部署至 GitHub Pages。部署是否成功仍以 Actions 實際執行結果為準。
