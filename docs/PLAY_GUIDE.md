# 《江湖》遊玩指南

## 開始遊戲
1. 安裝 Node.js 22 或更新版本。
2. 在專案目錄執行 `npm install`。
3. 執行 `npm run dev`，開啟終端機顯示的本機網址。
4. 選擇世界種子（留空會自動產生），建立虛擬台灣世界。
5. 點選縣市與中立／無主地盤，輸入組織名稱及領導人姓名，建立玩家組織。

## 每日經營
- **結束今天：**推進一天，結算收入、維持支出、人物狀態、AI 勢力、外交與世界事件。
- **地方公益：**消耗資金，提升聲望、信任並降低公共壓力。
- **內部治理：**消耗資金，提升團隊信任。
- **長期建設：**消耗資金，提高每日基礎收入。
- **招募核心幹部：**加入具備領導、管理與外交能力的人物；幹部會增加每日維持成本。

## 地盤
- 中立及無主地盤可透過地方管理行動取得。
- 玩家控制的地盤可投資，提升發展與穩定程度。
- 其他組織控制的地盤可進行公開協商或抽象地盤協調。
- AI 勢力會逐步累積影響力；與玩家關係惡化時，也可能對玩家控制區形成壓力。
- 所有競爭均以虛構的數值與敘事處理。

## 人物與家族
- 世界會為各組織建立領導人物。
- 人物會隨時間增長年齡，健康狀態也會變化。
- 領導者退休後，系統會優先由同家族在任人物接任；沒有合適人選時會生成下一代接班人。
- 人物資料包含家族識別、世代、能力、忠誠及健康。

## 外交與世界事件
- 可對各 AI 組織進行協商，逐步改善關係。
- 關係分為敵對、競爭、中立、友好及同盟。
- AI 組織之間的關係會隨時間微幅變動。
- 每週、年度及地方組織形成等事件會寫入世界事件與歷史紀錄。

## 存檔
- 自動存檔：1 槽。
- 手動存檔：10 槽。
- 存檔保存在目前瀏覽器的 IndexedDB；清除網站資料或更換瀏覽器前，請先匯出世界 JSON。
- 可匯出 JSON，並匯入至自動存檔槽。
- 舊版世界資料會在載入時升級至目前資料格式。

## 下載建置版
1. 開啟 GitHub 專案的 Actions 頁面。
2. 進入最新一次成功的 **Jianghu CI** 執行。
3. 在 Artifacts 下載 `jianghu-web-build`。
4. 解壓縮後，在該資料夾開啟終端機，執行 `python -m http.server 8080`。
5. 使用瀏覽器開啟 `http://localhost:8080`。

## 注意
《江湖》是單機虛構策略遊戲。人物、組織、地盤與事件皆為虛構；題材以抽象策略數值與敘事呈現。
